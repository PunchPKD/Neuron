A Discord AI infused Summary Bot by
Punch PKD in
Discord.py

This is my very first python project so ignore minor inconsistencies in codes

The bot works using two very simple process, first it collects data from the discord and converts it into conversation format
after that it passes that convo as a prompt to ai which summarises it and we simply post it back on discord

There are 2 branches in this repository one deals with data collection and the other one deals with AI stuff

From here on everything im going to talk about will be available in AI infused branch

To setup the bot you just need to enter your Discord bot and Ai APT token in .env file and install pacakages mentioned in requirementes file
you can get discord api token from discord.dev and 
AI api token from aistudio.google.com

i will recommend using Gimini Flash 2.0

Currently this bot has 4 commands, 2 slash commands, one user context cmd and one message context cmd
